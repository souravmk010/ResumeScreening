# ResumeScreening
📄 Resume Ranking System

A simple Resume Ranking System built using Python, Streamlit, and NLP to rank candidate resumes based on their similarity to a given Job Description.

# 🚀 Features

Enter Job Description

Upload multiple resumes (PDF, DOCX, TXT)

Automatically ranks resumes

Displays similarity score (%)

Shows simple charts for comparison

# 🛠️ Technologies Used

Python

Streamlit

spaCy

Scikit-learn

Pandas

Matplotlib

# 📂 Project Files

app.py – Streamlit user interface

ranking_engine.py – Resume ranking logic

requirements.txt – Required libraries

# ▶️ How to Run

Clone the repository:

git clone https://github.com/yourusername/Resume-Ranking-System.git
cd Resume-Ranking-System


Install dependencies:

pip install -r requirements.txt


Download spaCy model:

python -m spacy download en_core_web_md


Run the app:

streamlit run app.py

# 📊 Output

Ranked list of resumes

Similarity score in percentage

Visual comparison using charts

# 🎯 Purpose

This project helps automate resume screening by comparing resumes with job descriptions using NLP techniques.
